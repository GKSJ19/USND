## 🌍 U.S. Natural Disaster Dashboard

## 📌 Overview

The U.S. Natural Disaster Dashboard is an interactive web application that visualizes disaster-related data across the United States. It helps users explore patterns, trends, and geographical impacts of natural disasters in an intuitive way.


## 🚀 Live Demo

🔗 Deployment Link:https://u-s-natural-disaster-dashboard.vercel.app

## 🛠️ Tech Stack

- Frontend: React + TypeScript
- Build Tool: Vite
- Styling: CSS
- Data Visualization: Choropleth Maps
- Version Control: Git & GitHub

## ✨ Features

- 🌎 Interactive U.S. map visualization
- 📊 Disaster data representation by region
- 🔍 Easy-to-understand insights
- ⚡ Fast and responsive UI
- 📁 Structured project architecture
